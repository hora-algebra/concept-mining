# Stage 1: Map of AxiomMath/CFSG

This page records what we know about the structure of the upstream
formalization, how we extracted it, and which parts look promising for
stages 2 (Mine) and 3 (Pilot). All tables are generated by the scripts in
[`tools/`](../tools) and stored in [`data/`](../data); see
[Reproducing](#reproducing).

## Sources and versions

| Source | Version | What it gives |
|---|---|---|
| [AxiomMath/CFSG](https://github.com/AxiomMath/CFSG) | `965a077` (2026-11-19, head of `main` on 2026-11-21) | Lean sources |
| Data behind the [proof map](https://cfsg.axiommath.ai/proof-map) | built from upstream commit `3e39d10` | elaborated declaration graph |

The commit `3e39d10` named in the proof-map data is not in the public history
of AxiomMath/CFSG (which has four commits). How far it is from `965a077` is
**unverified**. Declaration counts agree closely: for `CFSG/FeitThompson` both
sources give 18,540 declarations.

The site data has no stated license (**unverified**). We do not redistribute
it; `tools/fetch_proofmap.py` downloads it into a local cache, and we commit
only derived tables.

No prebuilt `.olean` files or build cache are published as far as we could
find (**unverified** beyond the repository, its releases and the website).

## (c) Candidates for stages 2 and 3

### Stage 2: repeated material

**Parallel definitions of one concept.** The same notion is defined many times
under different names in different namespaces
([`parallel_definitions.tsv`](../data/map/parallel_definitions.tsv); the
grouping is by name only, so each group must be checked by hand).

| Concept | Separate definitions | Total direct users | Examples |
|---|---|---|---|
| p-core O_p | 6 | 111,514 | `Open.pCoreOf`, `pCore`, `FeitThompson.pCore`, `ABGTheoremB.pCoreIn` |
| quasisimple | 4 | 54,546 | `IsQuasisimple`, `Open.IsQuasisimple`, `Assembly.IsQuasisimple` |
| component | 10 | 37,336 | `Open.IsComponentOf`, `IsComponent`, `Assembly.IsComponentOf` |
| p′-core O_p′ | 5 | 34,790 | `pPrimeCore`, `GH74.GLS.pPrimeCoreOf` |
| p-rank | 2 | 33,069 | `Open.pRank`, `pRank` |
| Sylow subgroup predicate | 29 | 23,898 | `ABGLocalTools.IsSylowOf`, `Quasithin.IsSylowIn`, … |
| Sylow 2-subgroup predicate | 5 | 18,801 | `QuasithinUnique.IsSylowTwoOf`, … |
| odd core O(G) | 25 | 19,202 | `oddCore`, `ClassicalInvolution.Asc77.oddCoreOf`, … |
| subnormal | 4 | 16,008 | `Open.IsSubnormal`, `Assembly.IsSubnormal` |
| conjugate subgroup | 41 + 9 | 41,007 | `ClassicalInvolution.Generic.conjSub`, `Quasithin.conjSubgroup`, … |

Merging such a family is the simplest refactoring with a measurable effect:
every translation lemma between copies disappears.

**Repeated lemma names.** Final name components that occur in many namespaces
([`name_families.tsv`](../data/map/name_families.tsv)), e.g. `exists_frame`
(136 copies, 8,962 lines), `exists_decomp` (200), `mem_normalizer_of_conj_mem`
(260), `exists_mul_of_mem_sup` (214), `center_eq_bot` (175). These point to the
same argument restated for each local setting, concentrated in
`LocalAnalysis.StandardType` and `ComponentClassification`.

**Repeated assumptions.** From theorem statements
([`data/bundles/`](../data/bundles)): over 1.66 M theorems, 66,318 assume
`Finite G`, 41,834 `p.Prime`, 27,918 `p ≠ 2`, 16,773 `CharP K 2`. The most
frequent sets of three consecutive hypotheses include
`1 ≤ f, p ≠ 2, p.Prime` (1,011 theorems, 16 folders) and
`Nat.card K = p ^ f, p ≠ 2, p.Prime` (458 theorems, 7 folders), i.e. "K is a
finite field of odd characteristic" restated by hand; in `FeitThompson` the
minimal-counterexample context (simple, nonabelian, odd order, all proper
subgroups solvable) is restated in each theorem.

Suggested first ranges for stage 2:

| Range | Why |
|---|---|
| The p-core / p′-core / Sylow / component families across the library | largest measurable duplication; purely definitional |
| `FeitThompson` (209 k lines) | closed island (no outgoing edges), a known human proof to compare with, a clear repeated context |
| `LocalAnalysis.StandardType` | most of the repeated lemma names |

### Stage 3: pilot ranges

A pilot should be closed (few edges to the rest), of laptop size, and
mathematically recognizable. Two sources of candidates:

* dominator regions: a declaration together with everything that reaches the
  final theorem only through it, so that it can be rewritten without touching
  anything else ([`regions.tsv`](../data/map/regions.tsv), three size bands);
* the milestone theorems named by the site, with the proof size it reports
  ([`milestones.tsv`](../data/map/milestones.tsv); how the site counts "proof
  lines" is **unverified**).

| Candidate | Size | Notes |
|---|---|---|
| Dickson's list of subgroups of PSL(2, q) | 14.6 k proof lines (site) | classical, many parallel cases |
| Brauer–Suzuki theorem | 19.4 k proof lines (site) | classical, character theory |
| Glauberman ZJ theorem | 6.0 k proof lines (site) | short, standard textbook proof |
| `Goldschmidt75` folder | 7.2 k lines, 411 declarations | almost closed (861 edges out, 177 in) |
| `Holt` folder | 65.6 k lines, 3,715 declarations | almost closed; `Holt.H78.holtTheorem1` dominates 58 k lines |

## How the extraction works

**Exact graph (primary).** The proof-map site serves, for each declaration of
the compiled library, its kind, module, line range and the complete list of
declarations its elaborated term refers to (lists of users are truncated at
100, so in-degrees are recomputed from the dependency lists). The loader
checks that the edge count (17,211,386) and the number of declarations
reachable from the final theorem (2,053,885) match the site's own totals.
Mathlib and TauCeti declarations are outside this graph.

**Source scan (fallback, any commit).** `tools/scan_sources.py` reads `.lean`
files as text, tracks `namespace`/`open`, and resolves identifier tokens to
declarations by name. It needs no build. Against the exact graph:

| Directory | Declarations matched | Precision of edges | Recall of edges | Rank correlation of in-degree | Top-50 overlap |
|---|---|---|---|---|---|
| `CFSG/Dihedral` | 922 | 0.97 | 0.78 | 0.96 | 39 |
| `CFSG/FeitThompson` | 18,430 | 0.93 | 0.76 | 0.89 | 42 |

Missed edges are references created by elaboration (instances, `simp`
lemmas, tactic output). The whole of `CFSG/` (203,046 files, 2.0 GB) takes
16 minutes and 5 GB of memory on a laptop (Apple silicon), giving 1,992,679
declarations and 12.8 M edges.

**Not covered.** Neither method sees references into Mathlib or TauCeti, the
size of elaborated proof terms, or whether a refactored version still
compiles. Those need a build (stage 3 onward).

## Reproducing

```bash
# 1. exact graph (about 70 MB download, a few minutes)
python3 tools/fetch_proofmap.py --out ~/.cache/concept-mining/proofmap
python3 tools/analyze_proofmap.py --cache ~/.cache/concept-mining/proofmap --out data/map

# 2. Lean sources under CFSG/ only (about 2.3 GB on disk)
git clone --filter=blob:none --no-checkout --depth 1 https://github.com/AxiomMath/CFSG.git upstream/cfsg
cd upstream/cfsg && git sparse-checkout init --no-cone
printf '/*.lean\n/*.toml\n/*.json\n/*.yaml\n/lean-toolchain\n/CFSG/**/*.lean\n' > .git/info/sparse-checkout
git checkout && cd ../..

# 3. source scan, comparison, assumption bundles
python3 tools/scan_sources.py --root upstream/cfsg --dir CFSG/FeitThompson --out out/ft
python3 tools/compare_scan.py --cache ~/.cache/concept-mining/proofmap --scan out/ft
python3 tools/scan_sources.py --root upstream/cfsg --dir CFSG --out out/full
python3 tools/bundles.py --scan out/full --out data/bundles
```

`upstream/` and `out/` are ignored by git. All scripts use the Python standard
library only (tested with Python 3.14).
